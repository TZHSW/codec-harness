Codec Harness跨视频选参 · 机制

RSI 如何改变下一条视频的选参

RSI（递归自改进）让 Agent 在处理下一条视频时用上此前的编码经验。模型权重保持固定。

① 记录每次编码

保存每次实际使用的参数、对应的画质和码率。码率超限或画质下降的尝试也一并记录。

② 总结规则，编写工具

Agent 比较各轮结果，总结什么情况下值得调整哪些参数。它还可以编写工具，提取画面特征或推荐参数。

③ 在新视频上验证

平台检索相似案例，运行经过验证的工具。Agent 参考历史结果和工具建议选择参数，再编码测量实际效果。
