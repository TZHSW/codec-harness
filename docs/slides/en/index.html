Codec HarnessCross-clip search · Method

How earlier encodes guide the next search

Recursive self-improvement (RSI) lets the agent reuse encoding experience on the next clip. Model weights stay fixed.

1. Record each encode

Log the settings, quality and bitrate for every encode, including trials that exceed the cap or lose quality.

2. Derive rules and tools

The agent compares trials to identify when a parameter change helps. It can also write tools to extract frame features or propose settings.

3. Test on a new clip

The platform retrieves similar cases and runs validated tools. The agent uses them to choose settings, then tests those settings in a real encode.

The 10 training clips yielded 9 rules, 6 parameter tools and 2 frame-feature tools.

Find a similar clip

Frame features measure the area and intensity of change

For each new clip, sample 64 frames and resize each to a 32 × 18, 8-bit luma image. Both tools return the peak value and its frame number.

Peak area of change

For each pair of consecutive frames, find the share of pixels whose luma changes by more than 16 levels. Take the largest share across the clip.

Peak intensity of change

For pixels whose luma changes by more than 16 levels, average the absolute change. Take the largest such average across the clip.
